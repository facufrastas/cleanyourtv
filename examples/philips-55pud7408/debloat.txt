# Quirks on this firmware, all checked on the TV:
# - USB debugging + Network debugging opened port 5555 directly; the stock adb binary worked on macOS.
# - `screencap -p` prints "Init wrapper sys mutex successful" on stdout, so `adb exec-out screencap -p`
#   gives a corrupt PNG. Write to /sdcard and pull it. Live TV and HDMI screenshots are 0 bytes.
# - The Wi-Fi network saved during first setup belonged to setupwraith (cuid 10053). Forgetting it and
#   re-joining in Settings moved it to android.uid.system; only then was setupwraith disabled.
# - The remote's Settings (gear) button is scancode 357 (KEY_OPTION) with Android keycode 0, which only
#   launcherx answered. Launcher config: settings_key_scancodes = 357, installed with HOME_KEY_SERVICE=1.
#   Netflix, YouTube, Input, mic and Home keep working without the stock launcher.
# - At boot, system_server cleared enabled_accessibility_services of the helper ("Ignoring
#   non-encryption-aware service", then pkg:android writes null), so the Settings button died after
#   every restart. The launcher's helpers are now directBootAware; the setting survived a reboot after that.
# - org.droidtv.eum (the "Help" e-manual tile) is hidden in the launcher, not disabled (see philips-50pus8517).
# - Projectivy Launcher was installed and took Home through its accessibility service; it is disabled here.
